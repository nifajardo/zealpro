# Zealpro UI Demonstration Implementation Plan

> **For agentic workers:** Use executing-plans to implement these tasks inline. The owner requested autonomous local work.

**Goal:** Present the SRS business workflow through a branded, functional local browser demo.

**Architecture:** Static native modules render a shared demo dataset. Pure state functions validate mutations; a loopback server exposes only public UI files.

**Tech stack:** Node.js 22+, HTML, CSS, JavaScript, node:test.

**Spec:** `docs/superpowers/specs/2026-11-01-ui-demo-design.md`.

## Global constraints

- Preserve source paperwork and logo.
- Label illustrative data and browser-only persistence.
- No external messages, deployment or production security claims.
- Accessible controls, reduced motion, responsive layouts and safe user-text rendering.

## Review focus

- Repeated treatment submission must not deduct stock twice.
- Invalid quantities, insufficient stock and negative payments must leave state unchanged.
- Corrupt or inaccessible browser storage must keep the demo usable and disclose persistence limits.
- Empty searches and calendar days must show useful empty states.
- Static server must not expose the SRS, photographs, environment files or traversal paths.

## Tasks

- [x] 1. Write failing tests for summaries, scheduling validation, atomic fulfillment, stock, payments and storage validation. Implement `src/model.js` and `src/data.js`; run `node --test`.
- [x] 2. Build `public/index.html`, `src/app.js`, `public/styles.css`, `public/tokens.css`, supplied logo and a loopback static server. Implement the eight destinations and connected local actions. Verify HTTP allowlist and syntax.
- [x] 3. Verify desktop, tablet and phone output; exercise calendar, report, inventory, billing and empty/failure states. Run Hallmark and Taste inspections; record limitations.
- [x] 4. Document setup, client walkthrough, requirements traceability, skill availability and continuation state. Build a local Graphify source map and verify it against source. Run final checks.
